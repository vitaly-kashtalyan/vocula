Vocula — third-party licences
=============================

Vocula performs speech recognition entirely on this machine. It carries the
third-party components listed below — the recognition engine and the models it
runs, and the framework that installs its own updates. Each is reproduced in full, verbatim, as its licence
requires. Nothing here has been edited.

The short identification shown beside each model in Settings → Models is a
summary of these terms; this file is the terms themselves.

Sources, so that any line here can be checked against the original. Each is
pinned to the version this build actually carries, not to a moving branch:

  whisper.cpp     https://github.com/ggml-org/whisper.cpp/blob/v1.9.2/LICENSE
  Silero VAD      https://github.com/snakers4/silero-vad/blob/v5.1.2/LICENSE
  OpenAI Whisper  https://github.com/openai/whisper/blob/v20250625/LICENSE
  Sparkle         https://github.com/sparkle-project/Sparkle/blob/2.9.6/LICENSE

whisper.cpp is linked as a prebuilt XCFramework rather than compiled here. Its
corresponding source is the tag above; the exact artefact this build links is

  https://github.com/ggml-org/whisper.cpp/releases/download/v1.9.2/whisper-v1.9.2-xcframework.zip
  SHA-256  af74fed13ea7f2d5ca2a39d9f58ec177713fafd7cab63aef4e27b79f3ceca80b
